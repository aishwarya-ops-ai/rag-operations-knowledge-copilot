Local RAG portfolio project

Answers grounded in operational knowledge.

A practical retrieval-augmented generation system for asking questions about SOPs, policies, and training documents—with visible evidence, citations, refusal behavior, feedback, and evaluation.

Run it locally Explore the code
Portfolio page, not a hosted copilot. GitHub Pages cannot run the Python, Chroma, or Ollama backend. The working Streamlit application runs locally on a Mac; all included source documents are synthetic.

What it demonstrates

Transparent retrieval

Local MiniLM embeddings and Chroma cosine search return source filenames, chunk numbers, scores, and full supporting excerpts.

Grounded answers

A local Ollama model answers only from retrieved evidence. Citation validation and an evidence threshold reject unsupported output.

Measured limitations

Canonical, paraphrase, and unanswerable tests expose retrieval weaknesses instead of presenting the system as production-ready.

RAG workflow

TXT documents→ Chunking→ Local embeddings→ Chroma retrieval→ Evidence gate→ Ollama answer→ Citations + feedback
